<details>
<summary><b>📱 Publicar una app de Flet en Android (pasos y comandos)</b></summary>

<br>

**Requisitos:** Android SDK · Flutter SDK 3.16 o superior · Java JDK compatible con Gradle ([tabla de compatibilidad](https://docs.gradle.org/current/userguide/compatibility.html#java))

```bash
flet create <myapp>   # crea el proyecto con la carpeta assets y main.py
flet build apk        # genera el .apk dentro de la carpeta build
```

</details>
